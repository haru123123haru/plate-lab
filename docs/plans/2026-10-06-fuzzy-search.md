# 検索を、打ち間違いや表記の揺れに強くする（2026-10-06）

作成: 2026-10-06

## 目的

今の検索（`lib/actions/plates.ts` の `searchPlates`）は、プレート名・サンプル名・タイプ名・メモの部分一致（大文字小文字を区別しない）だけで探している。`lysozme` のように1文字打ち間違えると、何も見つからない。PostgreSQL の `pg_trgm` を使い、似ている名前でも見つかるようにする。

## 決めたこと

### 部分一致は残し、似ているものをあとに続ける

部分一致で見つかったプレートを今までどおり先に（更新が新しい順で）並べ、似ているだけのプレートをそのあとに、似ている順で並べる。混ぜて並べ替えると、ちゃんと当たったものが下に埋もれるため。似ているだけのプレートは50枚まで。

### 似ているの測り方

`word_similarity(検索語, 列) >= 0.6`（`<%` 演算子と同じ既定のしきい値）。長いメモの中の1語に似ていても拾える。`lysozme` は `Lysozyme`・`T4 Lysozyme`・`lysozyme 10mg/ml in tris` に 0.625 で当たり、`Thaumatin` や `HEWL` には当たらない。

- 対象はプレート名・メモ・サンプル名。タイプ名は一覧から選んだ名前なので入れない
- 2文字以下の検索語は部分一致だけにする。`ly` は `Lysozyme` に 0.67 で当たり、似ているものが出すぎる

### 作り

- マイグレーションで `pg_trgm` を `extensions` スキーマに入れる（Supabase の決まり）。すでに別のスキーマに入っていても動くよう、関数はスキーマを付けずに `search_path`（`public, extensions`）で引く
- データが少ないので索引は作らない。schema.prisma とのずれも出ない
- Prisma では似ているかを書けないので、似ているプレートの ID だけを `$queryRaw` で引く。SQL の持ち主とゴミ箱の条件は候補を減らすためのもので、守るのは、部分一致と同じ `findMany` の条件（`activePlateWhere` とタイプ）でかけ直すところ
- 似ているものを探すのは付け足しなので、失敗しても（`pg_trgm` が無いなど）部分一致の結果は返す

### 一覧の並べ方を変えられるようにする（2026-10-09 に追加）

ホームとサンプル画面の検索欄の下に、並べ方のボタンを3つ並べる。「更新が新しい」（今までと同じ、既定）・「仕込みが新しい」・「仕込みが古い」。「作成日」は、前に作成日を自分で決めたいという声から足した仕込み日（`setupDate`）のこと。同じ仕込み日のあいだは更新が新しい順。

- 並べ替えはブラウザでする（`lib/plate-sort.ts` の `sortPlates`）。一覧は全件を読んでいるので、サーバーに聞き直さなくてよい
- 検索中は、部分一致のプレートを先に、似ているだけのプレートをあとに置く。既定の並べ方では似ているものを似ている順のままにし、仕込み日で並べるときは似ているものも仕込み日の順にする。仕込み日で並べると選んだのに、似ている順のままだと分かりにくいため。`searchPlates` は似ているだけのものに `similar` を付けて返す
- 選んだ並べ方は `localStorage` に覚え、ホームとサンプル画面で共通にする。読めないときは既定の並べ方
- ホームの見出しは、更新順のときだけ「最近のプレート」、ほかは「プレート」


- 濃度や日付から探すこと、意味で探すこと（AI を使う検索）
- 似ている度合いでの並べ替え、似ている結果の目印

## 結果

- ローカルで Playwright を使い、`lysozme` で、Lysozyme 系のサンプルが入った5枚が出ることを確かめた。DB で同じ条件を直接引いた結果と合っていた。変更前は「プレートが見つかりません」だった
- 日本語でも効く。DB の照合順序が `en_US.UTF-8` なので、`リゾチム` は `リゾチーム 10mg` に 0.6 で当たる
- レビューを受けて4つ直した。似ているものを探すのに失敗しても部分一致は返す、関数にスキーマを付けない、似ている順に並べて50枚までにする、ヘルプにホームの検索とプレート名・メモも対象になることを書く
- 直さなかったもの: 遅れて届いた古い検索の結果が新しい結果を上書きしうること（前からあり、ホームとサンプルの画面の話）。タイプ名を対象にしないこと（一覧から選んだ名前なので）
- 本番に `pg_trgm` を入れるのは、この PR をマージしたときのデプロイ（`prisma migrate deploy`）
- 並べ方: ローカルで Playwright を使い、ホームで「仕込みが古い」を押すと DB の仕込み日の順に並び、サンプル画面に移っても同じ並べ方になることを確かめた。402px で3つのボタンが1行に収まるよう、文言を短くした
- ドロップや観察を足しても `Plate.updatedAt` は変わらない（`docs/architecture.md` の残りの課題）。「更新が新しい」は、プレートそのものを直した順
- 並べ方のレビューを受けて4つ直した。既定の並べ方では似ている順を残す、覚えられなかったときもその場で選んだ並べ方を使う、別のタブで選び直したら合わせる、打つたびに並べ直さない
- 前からあった、遅れて返った古い検索の結果が新しい結果を上書きするバグも直した（似ているものの検索で起きやすくなったため）。最後に始めた検索の結果だけを使う
