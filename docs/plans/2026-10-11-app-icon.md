# アプリのアイコンを作り直す（2026-10-11）

作成: 2026-10-11 / Issue #1

## 目的

今のアイコンは、2026-04-13 に仮で入れたもの（DNA の二重らせんとトレイの絵）。本人は「そろそろいい感じのやつにする」と考えている。ホーム画面に追加して使う人が増えるので、ホーム画面・タブ・通知（`docs/plans/2026-10-11-notifications.md`）で見分けやすいアイコンにする。

## 今のアイコンの問題

- 絵の外側の四隅が暗い色で塗られている。iPhone のホーム画面は角を丸く切り抜くので、その切り抜きの内側に、元の絵の角丸と暗い隅がもう一段見える
- 細い線が多く、タブの 16〜32px では潰れる
- `app/icon.png` が正方形でない（487×492）
- Android のアダプティブアイコン用（`purpose: "maskable"`）が無い。丸や角丸に切り抜かれると、絵の端が欠ける
- `app/plate-lab-favicon.png` は、どこからも使われていない

## 決めたこと（案）

### 作り方

- 元の絵は SVG で1つ作り、そこから各サイズの PNG を書き出す。書き出しの手順はスクリプトにして残す（`scripts/` か `docs/`）
- 絵の題材は、このアプリが何をするかが分かるもの。候補は、上から見たウェルプレート（丸い穴の格子。1つだけ結晶の目印の色が付いている）。らせんはタンパク質の結晶化と結びつきにくいので外す
- 小さくても潰れないよう、線は太く、要素は少なく。格子は 3×3 か 4×4 程度に省く
- 背景は全面を塗り、透明や暗い隅を残さない

### 書き出すもの

| ファイル | 大きさ | 使い道 |
| --- | --- | --- |
| `app/icon.svg` | — | タブのアイコン（新しいブラウザ） |
| `app/icon.png` | 32×32 | タブのアイコン（SVG が使えないとき） |
| `app/apple-icon.png` | 180×180 | iPhone のホーム画面 |
| `public/icon-192x192.png`・`public/icon-512x512.png` | 192・512 | manifest（`purpose: "any"`） |
| `public/icon-maskable-512x512.png` | 512 | manifest（`purpose: "maskable"`）。絵を中央 80% に収める |

あわせて、`app/manifest.ts` の `theme_color`・`background_color` を、アイコンの色に合わせて見直す。

## 進め方

1. 案を3つほど SVG で作り、ホーム画面（iPhone・Android の切り抜き）とタブの大きさに並べた見本を、本人に見てもらう
2. 選んだ案を仕上げ、上の表のファイルを書き出す
3. 使っていない `app/plate-lab-favicon.png` を消す

## タスク

- [x] 案を選んでもらう（本人が ChatGPT で作った、フラスコと DNA の絵に決めた）
- [x] 書き出しのスクリプト（`scripts/generate-icons.mjs`。元の絵は `scripts/icon-source.png`）
- [x] 各サイズの PNG と `app/manifest.ts`
- [x] `app/plate-lab-favicon.png` を消す

## 確認

`npm run check` が通る。Playwright で、タブのアイコンと manifest のアイコンが新しいものになっていることを確かめる。本番に出たあと、本人の iPhone でホーム画面に追加し直して、見た目を確かめる（iPhone はアイコンをキャッシュするので、一度消してから追加する）。

## 結果

- 絵は、本人が ChatGPT で作ったもの（フラスコの中に DNA のらせん、白地に黒）にした。SVG ではなく 1254×1254 の PNG なので、`app/icon.svg` は作っていない
- 元の絵は角丸の外の四隅が黒く、白も 250〜254 でむらがあった。`scripts/generate-icons.mjs` で、四隅を白く塗り、明るい画素を真っ白にそろえ、絵の範囲を切り出して、大きさごとに余白を付けて書き出す
- 絵が全体に占める割合: タブ（32px）は 90%、ホーム画面と manifest の `any` は 68%、`maskable` は 54%（丸く切り抜かれても欠けない）
- 絵を差し替えるときは、`scripts/icon-source.png` を置き換えて `node scripts/generate-icons.mjs` を実行する
