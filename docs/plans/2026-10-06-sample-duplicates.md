# 名前の揺れで別になったサンプルを見つけて、まとめる（2026-10-06）

作成: 2026-10-06

## 目的

`lysozyme` と `Lysozyme`、`T4-lysozyme` と `T4 lysozyme` のように、同じサンプルが名前の揺れで別のサンプルになってしまうことがある。CSV の取り込みは、既にあるサンプルと名前が重なっても止めないので、揺れが増えやすい。

今でも管理ページ（`/settings/samples`）で名前を変えればまとめられるが、どれが揺れているかを自分で探さないといけない。管理ページで揺れを見つけて出し、その場でまとめられるようにする。

## 決めたこと

### 「同じ」とみなす名前

次をそろえた名前が同じなら、揺れとみなす（`lib/samples.ts` の `sampleNameKey`）。

- 全角と半角（Unicode の NFKC。`ＨＥＷＬ` と `HEWL`、`１` と `1`）
- 大文字と小文字
- 空白・`-`・`_`・`.` の有無（`T4-lysozyme` と `T4 lysozyme`）

綴りの違い（`Lysozym` と `Lysozyme`）は拾わない。似ている度合いで拾うと、`Lysozyme A` と `Lysozyme B` のような別のサンプルも出てしまう。綴りの違いは、今までどおり名前の変更でまとめる。

### 出し方

管理ページの一覧の上に「名前の揺れ」の欄を出す。揺れが無ければ欄を出さない。

- 揺れているグループごとに、名前のチップとドロップ数を並べる
- 名前を押すと「『X』にまとめますか？」と確かめ、残りの名前のドロップを X に変える
- 残す名前の見た目を残し、他の名前の見た目の行は消す（名前の変更でまとめるときと同じ）

### まとめる処理

`mergeSamples({ from: string[], into: string })` を足す。名前ごとに `updateSample` を呼ぶと途中で失敗したときに半分だけまとまるので、1つのトランザクションでまとめる。名前の変更と同じく、ゴミ箱のプレートのドロップも書き換える。

一覧はゴミ箱に無いプレートのドロップから組み立てているので、ゴミ箱のプレートにしか無い名前は揺れとして出ない。

## やらないこと

- 綴りの違いや似ている名前を拾うこと
- CSV の取り込みのときに揺れを知らせること

## 確認

`npm run check` が通る。ブラウザ（Playwright、402px）で次を確かめる。

- `Lysozyme` と `lysozyme` のドロップがあると「名前の揺れ」に出て、片方を押すとまとまり、欄が消える
- 揺れが無いときは欄が出ない

## 結果

- テストは `tests/samples.test.ts`（4件）と、`tests/sample-actions.test.ts` に足した `mergeSamples` の4件
- ローカルで Playwright を使い、CSV で `Lysozyme`・`LYSOZYME`・`T4-lysozyme`・`T4 Lysozyme`・`HEWL`・`ＨＥＷＬ` を入れると、3つのグループが出ることを確かめた。`Lysozyme` を押して確かめると、`LYSOZYME` の1ドロップが `Lysozyme` にまとまり、そのグループが欄から消えた
- 確認に出すドロップ数は、一覧と同じくゴミ箱に無いプレートのドロップの数。ゴミ箱のプレートのドロップも書き換えるので、確認の文にそう書いた
- レビューを受けて3つ直した。サーバーで `from` の名前が `into` の揺れかを確かめる。確認の文に名前を関数で差し込む（名前の中の `$&` などが置き換えの記号にならないように）。グループの並びに `localeCompare` を使わない（サーバーとブラウザで並びが変わらないように）
- まとめるときに、残す名前の見た目が無く他の名前に見た目があっても、引き継がない。名前の変更でまとめるときと同じ動き
